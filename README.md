# Klant Demo Website

Een eenvoudige, responsive demo-website voor een fictief webdesignbedrijf.

## Pagina's
- `index.html`: homepage
- `about.html`: informatie over het bedrijf
- `contact.html`: contactgegevens en contactformulier

## Gebruikte technieken
HTML5 en CSS3. Er zijn geen externe bibliotheken nodig.

## Starten
Open `index.html` in een webbrowser.
